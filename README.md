# WorkloadTaskDashboard

工数とタスクを一覧で管理できる **業務システム風ダッシュボード** です。  
Visual Studio Code を使用して作成し、HTML/CSSのみで構成しています。

実務でよく使われる「一覧画面」「ステータス管理」「工数サマリー」を  
シンプルなUIで再現することを目的としています。

---

## 📌 特徴

- **工数サマリー表示**
  - 今週の作業時間を上部にまとめて表示

- **タスク一覧テーブル**
  - 日付 / タスク名 / 工数 / ステータス を一覧で確認可能

- **ステータスの色分け**
  - 未着手：グレー  
  - 対応中：オレンジ  
  - 完了：グリーン  

- **業務画面を意識したUI**
  - 落ち着いた配色  
  - 余白と行間を意識した読みやすいレイアウト  
  - 実務で使われる管理画面の雰囲気を再現

など、実務でよく見られる画面構成を意識して制作しました。
